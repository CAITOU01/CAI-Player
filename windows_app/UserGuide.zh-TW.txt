CAI Player V0.06

Windows 免安裝版

請先解壓縮整份免安裝包，保留同資料夾的 DLL，再雙擊 CAI Player.exe。這個版本使用 Windows 內建的 .NET Framework 與媒體解碼器。按「加入音檔」可直接從電腦選歌，雙擊歌名開始播放。按「加入網址」可輸入音訊串流的 HTTP 或 HTTPS 直接連結。

音樂資料夾與歌庫

在主視窗左側點選已儲存的清單即可開啟。點「近期新增」可看最新 20 首，音樂資料夾內的歌曲依檔案建立時間排序，手動加入的歌曲依加入時間排序。「近期播放」列出最近播放的 20 首不同歌曲，重播會移到最前面。兩份清單都在開啟時更新。

滑鼠停在 Windows 工作列上的 CAI Player 圖示時，可在縮圖下方按上一首、播放／暫停或下一首。主視窗最小化時也可操作。

按「音樂資料夾」，貼上完整路徑後按「新增」，或按「瀏覽…」選取資料夾。可新增多個路徑，使用「上移」、「下移」調整搜尋順序，最後按「儲存」。設定會保存在目前 Windows 使用者帳戶，下次開啟播放器會自動掃描。

每個路徑只掃描最外層。例如加入 D:\Music 時，要收錄 D:\Music\Live 裡的歌曲，請把 Live 也新增為一個路徑。外接硬碟暫時離線時會保留設定。重新接上或新增音檔後，在歌庫裡再按一次「音樂資料夾」和「儲存」即可重新掃描。

使用原有的 EDM 清單

1. 按「匯入清單」，開啟隨附的 EDM(no nightcore).m3u8。
2. 畫面應顯示 68 首歌。這份範例只有曲目與檔名。按「音樂資料夾」，新增存放對應 MP3 的資料夾並儲存，再雙擊歌曲。
3. 清單使用相對路徑時，程式依設定順序尋找音檔，再嘗試清單所在位置。調整設定時會保留目前清單；勾選「儲存後開啟資料夾歌庫」即可切回歌庫。

我的播放清單與音樂庫

「我的播放清單」可將目前佇列另存為具名清單，或從空白清單開始。開啟具名清單後，新增、移除、編輯與排序會自動儲存。下次開啟程式後，可從「我的播放清單」找回，也可重新命名或刪除。要加入另一份清單時，先在主視窗選取歌曲，再到「我的播放清單」選取目標並按「加入選取的歌曲」。跨電腦使用請匯出清單並帶上音檔。

「音樂庫」可搜尋歌名、演出者、專輯、類型或路徑。選取歌曲後可立即播放、排為下一首或加入佇列。左上角可切換到最近播放或影片庫；影片庫有獨立的資料夾設定。

播放器圖示可用滑鼠停留查看中文說明。喇叭可靜音，速度按鈕可選 0.5 至 2 倍速；Ctrl 加左右方向鍵可前後跳十秒。等化器可調整本機音樂的十個頻段，按「平坦」及「套用」可還原。迷你播放器會浮在其他視窗上，按返回圖示即可回到主視窗。

按影片圖示可開啟本機影片，按兩下影片切換全螢幕。程式可讀取與影片同名的 SRT 或 VTT 字幕，在畫面上按右鍵可選擇其他字幕或關閉字幕。影片格式依 Windows 安裝的解碼器而定。

按「音樂 CD」圖示可選擇光碟機、播放音軌，或將選取的音軌擷取成無損 WAV 或 FLAC。也可使用 Windows 編碼器儲存 MP3、AAC、WMA 或 Apple Lossless。

時長、封面與頻譜

匯入清單、加入音檔或指定音樂資料夾後，播放器會在背景讀取未知的曲目時長。串流則在來源提供總長時顯示。若仍顯示「—」，可將滑鼠停在該曲目查看提示。

播放中橫幅會顯示歌曲封面及迷你頻譜，各頻帶的高度代表強度。按右上角「大視窗模式」、按兩下橫幅，或按 F11，可放大封面與頻譜並保留播放控制。大視窗會直接標示 20 Hz 至 20 kHz 的頻段。按 Esc 或「返回清單」即可收合。

本機音檔會優先讀取標記為正面的內嵌圖片，圖片損壞時會嘗試其他內嵌圖片與外部封面。外部封面可以用曲名、專輯名或 cover、folder、front、albumart 等名稱，支援 JPG、PNG、WebP、BMP 與 GIF。沒有可讀的封面時顯示唱片圖案。頻譜依播放位置從本機音檔計算，網路串流暫無頻譜。

播放順序

開啟「隨機」後，每一輪會打散曲目，並讓清單中的每一項各播放一次。按「上一首」可回到剛才聽過的歌曲。隨機播放與單曲循環互斥，開啟其中一項會自動關閉另一項。

循環關閉時，播完最後一首便停止。單曲循環會在歌曲結束時重播該曲，手動切歌仍可跳到其他曲目。播放清單循環會在播完整份清單後開始下一輪。隨機與循環可以搭配使用。

編輯與匯出

選取歌曲後可修改名稱與路徑。拖曳歌曲或按「上移」、「下移」可調整順序。「移除」只會把歌曲移出清單。

按「匯出清單」另存新檔。預設產生 VLC 可開啟的 UTF-8 M3U8，並依輸出位置計算相對路徑。需要保留原本的檔名寫法時，可選「保留清單原有路徑」。

「歌曲路徑」下方會依選項顯示範例。假設音樂資料夾為 C:\Music，匯出位置為 C:\Playlists：
  相對於匯出檔案的位置    ../Music/Album/song.mp3
  保留清單原有路徑        Album/song.mp3
  完整路徑                C:\Music\Album\song.mp3

也可匯出 JSON，或選擇「自訂文字範本」設定副檔名、欄位與分隔符號。例如輸入 {index}{sep}{title}{sep}{path}，可輸出序號、歌名和路徑。自訂文字範本僅供匯出。重新匯入編輯可使用 M3U8 或 JSON。

Ctrl+O 可匯入，Ctrl+S 可匯出。在歌曲清單中，空白鍵控制播放與暫停，F2 編輯歌曲。右上角可切換深色與淺色模式。
